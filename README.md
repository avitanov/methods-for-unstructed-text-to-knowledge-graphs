# Text-to-Knowledge-Graph Review

This is the writing corpus for a review of methods that transform unstructured text into knowledge graphs.

## Start here

- `paper/review-paper.md` — editable review-paper source.
- `paper/review-paper.pdf` — professionally formatted 24-page A4 review paper.
- `paper/review-paper.docx` — editable Microsoft Word version of the review paper.
- `paper/review-paper-print.css` — print styling used for the PDF.
- `paper/supplementary-search-protocol.md` — complete search formulations and source-level candidate counts.
- `data/review/synthesis-matrix.csv` — cross-paper comparison table for drafting.
- `data/review/reproducibility-audit.csv` — paper-level code, data, and LLM-version reporting judgments used for the manuscript statistics.
- `data/review/search-query-log.csv` — detailed search-query audit.
- `data/review/discovery-records.csv` — records entered through Elicit and Connected Papers.
- `data/review/connected-papers-graph-results.csv` — result-level export of the available Connected Papers graphs.
- `data/review/final-corpus-status.json` — internal collection status.
- `analysis/search-protocol-reconstruction.md` — evidence and arithmetic supporting the reported selection flow.
- `analysis/corpus-saturation-assessment.md` — methodological coverage and synthesis decision.
- `analysis/final-collection-status.md` — current collection status.
- `paper/` — review manuscript and bibliography.

## Scope note

The review synthesizes the successfully obtained and analyzed corpus. It covers all 12 methodology families in the project taxonomy, while treating fine-tuned LLM methods, temporal updating, event extraction, and standardized human evaluation as bounded evidence gaps.
